# Automatic Network Anomaly Detection using Mixture of Experts on UNSW-NB15

This project implements a multiclass intrusion detection system on the UNSW-NB15 dataset using a Mixture of Experts (MoE) neural network in PyTorch.

## Project structure

- `data/raw/`: place the original UNSW-NB15 CSV files here (either the four-part variant `UNSW-NB15_1.csv`–`UNSW-NB15_4.csv` or the training/testing CSVs).
- `data/splits/`: contains processed `train.csv`, `val.csv`, `test.csv` generated by Notebook 1.
- `models/`: contains the trained model and preprocessing artifacts.
- `notebooks/`:
  - `1_data_processing.ipynb`: preprocessing, encoding, scaling, splitting, and class-weights computation.
  - `2_training.ipynb`: Mixture of Experts model training with early stopping and class-weighted loss.
  - `3_evaluation.ipynb`: evaluation on the test set with metrics, confusion matrix, and training curves.

## Usage

1. Download the UNSW-NB15 dataset CSV files from the official source and place them under `data/raw/`.
2. Open and run `notebooks/1_data_processing.ipynb` to generate processed splits and artifacts.
3. Open and run `notebooks/2_training.ipynb` to train the MoE model.
4. Open and run `notebooks/3_evaluation.ipynb` to evaluate the trained model and visualize results.
5. Run the streamlit UI by running command:
```bash
py -3.11 -m streamlit run app.py
```
Ensure the required Python packages are installed (PyTorch, scikit-learn, pandas, numpy, matplotlib, seaborn, joblib).
